# 📚 Resumo das Aulas

## 🔹 Aula 02 - Configuração do Ambiente de Desenvolvimento
* **Tecnologias Envolvidas:** Git, GitHub, Node.js, NPM, VS Code, Vercel, React.
* **Tópicos Abordados:** Diferença entre backup e versionamento; Versionamento Semântico (SemVer: `MAJOR.MINOR.PATCH`); comandos fundamentais e boas práticas do Git (tags, branches e mensagens de commit); ecossistema do Node.js/NPM; inicialização e estrutura de projetos React; fluxo de *Continuous Deployment* (CD) automatizado na Vercel.

## 🔹 Aula 03 - Projetos com Frameworks Front-End
* **Tecnologias Envolvidas:** React, Vue.js, Angular, Next.js, Vite, Angular CLI, CodeSandbox.
* **Tópicos Abordados:** Diferenças conceituais entre bibliotecas e frameworks (*Inversão de Controle*); características do ecossistema front-end moderno (componentização, programação reativa, bundling com Vite e roteamento); arquitetura de projetos em React, Angular (TypeScript nativo, CLI, MVC), Vue.js (Single-File Components) e Next.js (App Router, SSR, Server Components); reutilização de *templates open-source*.

## 🔹 Aula 04 - Consumindo APIs no Front-End
* **Tecnologias Envolvidas:** JavaScript / Node.js, Express.js, Protocolo HTTP, JSON, CORS, Render.
* **Tópicos Abordados:** Fundamentos de arquiteturas REST e comunicação stateless; protocolo HTTP (métodos `GET`, `POST`, `PUT/PATCH`, `DELETE` e idempotência); estrutura e manipulação de arquivos JSON; mapeamento de *Endpoints*; criação de servidores web simples com Express.js e tratamento de requisições de origens cruzadas (CORS); hospedagem e *deploy* de Web Services no Render.

## 🔹 Aula 05 - Criando APIs para o Front-End
* **Tecnologias Envolvidas:** Node.js, Express.js, Body-Parser, Módulo Nativo `fs`, Postman, Render, React, Vercel.
* **Tópicos Abordados:** Construção completa de uma API RESTful CRUD (*Create, Read, Update, Delete*) com persistência de dados local; refatoração e boas práticas de arquitetura de software (divisão de responsabilidades, middleware e segurança); discussão crítica sobre persistência em JSON vs. Bancos de Dados em produção; documentação e testes automatizados de endpoints utilizando Coleções no Postman; integração Fullstack conectando API em produção na Render com aplicação React na Vercel.

## 🔹 Aula 06 - Projetos Front-End e Gestão Ágil
* **Tecnologias Envolvidas:** Git, GitHub Projects, Framework Scrum, Markdown.
* **Tópicos Abordados:** Metodologias ágeis aplicadas ao desenvolvimento front-end; prevenção de débitos técnicos, conflitos de código e atrasos; decomposição de escopo (Requisitos → User Stories → Tarefas Operacionais); gestão e priorização de Backlog; estimativas de esforço; aplicação do framework Scrum (Sprints e Kanban); definição clara de *Definition of Done* (DoD).

## 🔹 Aula 07 - Frameworks CSS
* **Tecnologias Envolvidas:** HTML5, CSS3 Nativo, Flexbox, Tailwind CSS, PostCSS, Vite, VS Code (Tailwind IntelliSense).
* **Tópicos Abordados:** Evolução do estilo web (In-line, Interno e Externo); domínio do *Box Model* (Content, Padding, Border, Margin); layouts unidimensionais com Flexbox (eixos, alinhamentos e responsividade); design responsivo com a tag `viewport`; introdução aos frameworks CSS; arquitetura *Utility-First* do Tailwind CSS; otimização do tempo de desenvolvimento, padronização visual e integração de classes utilitárias via CDN e Tailwind CLI.

## 🔹 Aula 08 - Projeto React & Fundamentos JS
* **Tecnologias Envolvidas:** JavaScript Moderno (ES6+), React, Virtual DOM, JSX, Babel.
* **Tópicos Abordados:** Revisão profunda de JS (escopos `var`/`let`/`const`, operadores, estruturas condicionais/repetição, arrow functions e manipulação avançada de Arrays e Objetos); manipulação nativa do DOM vs. modelo declarativo; sintaxe JSX e expressões JavaScript `{}`; criação, composição e reutilização de Componentes; fluxo unidirecional de dados com *Props*; funcionamento interno do *Virtual DOM* e ciclo de *Reconciliação*; renderização de listas dinâmicas com métodos `map()`/`filter()` e importância das `keys` únicas; estratégias de renderização condicional na interface.

## 🎯 Por que dominar essas tecnologias e o que as atividades me ensinaram?

O desenvolvimento Front-End moderno vai muito além de criar páginas visuais: trata-se de arquitetar experiências digitais eficientes, escaláveis e perfeitamente integradas a serviços em nuvem. A vivência prática adquirida ao longo das atividades destas aulas proporcionou aprendizados fundamentais para a minha formação técnica e profissional:

* **Evolução da Lógica de Programação e Solução de Problemas:** A transição do JavaScript imperativo para o paradigma declarativo e reativo do React (além da construção de APIs em Node.js) elevou a minha capacidade de abstração, decomposição de problemas e estruturação algorítmica.
* **Otimização e Qualidade de Código:** Compreender o funcionamento interno do *Virtual DOM*, a importância das *keys* em listas, o impacto da especificidade no CSS/Tailwind e as nuances do modelo *stateless* do HTTP me ensinaram a escrever códigos limpos, performáticos e sustentáveis.
* **Inteligência Artificial como Aliada Estratégica:** A utilização de ferramentas de IA ao longo dos estudos provou que a tecnologia atua como um acelerador de produtividade — auxiliando na depuração de erros, refinamento de sintaxes e prototipagem rápida —, e não como um substituto do raciocínio crítico e da arquitetura do desenvolvedor.
* **Expansão do Repertório Front-End & Ecossistema Moderno:** Trabalhar lado a lado com os principais ecossistemas do mercado (**React, Vue, Angular, Next.js e Tailwind CSS**) me deu autonomia para avaliar e escolher a ferramenta certa para cada tipo e porte de projeto.
* **Domínio de APIs, Integrações e Deployment:** Aprender a criar, consumir, testar (via Postman) e documentar APIs RESTful, somado à experiência prática de publicar serviços na **Vercel** e no **Render**, consolidou a minha visão de ciclo completo (*end-to-end*) de uma aplicação web.
* **Visão Ágil e Engenharia de Software:** A aplicação dos conceitos de Scrum, versionamento com Git/GitHub e definição de critérios de entrega (*Definition of Done*) me preparou para atuar em equipes de tecnologia de alto desempenho, garantindo entregas organizadas, previsíveis e alinhadas às demandas do mercado.
